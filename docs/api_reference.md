## Client API

The `joern_server.client` module provides a synchronous HTTP client to query and interact with Joern Server replicas, supporting session affinity and round-robin request distribution.

## Proxy API

The `joern_server.proxy` module coordinates request forwarding, authentication, on-disk CPG caching, file ingestions, and structured graph serialization.
